# 小説の作業机

## すぐ試す

ZIP版は「すべて展開」してから index.html をブラウザで開きます。index.html・desk.js・style.css は同じフォルダに置いてください。単体HTML版「小説の作業机.html」は、そのまま開けます。

作品一覧で「続きを書く」を押すと執筆画面になります。「相談例を試す」→「相談する」→「この案の見本を頼む」→「相談する」の順に操作できます。
気に入った案や見本は「メモに残す」で保存できます。体験モードでは、サンプル小説向けの用意済みの回答が出ます。

小説の作成、作品名・ジャンル・あらすじの編集、各話の追加と執筆ができます。設定ノートは作品管理画面から編集できます。本文や作品ノート、相談履歴は、このアプリを開いたブラウザに保存されます。バックアップを書き出し、「読み込み」で他の場所にも移せます。読み込みは新しい作品として追加します。同じ場所で使っていた旧版の原稿は自動で引き継ぎます。
HTML ファイルを直接開いた場合と、下のローカルサーバーを使う場合では、ブラウザ上の保存先が別になります。

## Gemini を接続する

Google AI Studio で対象プロジェクトの Billing Tier が Free Tier であることを確認し、請求先が未設定のプロジェクトの API キーを使います。
このアプリからは Google 側の課金状態を照会できません。無料枠のデータの取り扱いは Google の利用規約をご確認ください。

このフォルダで PowerShell を開き、Node.js 22 以降が使える状態で以下を実行します。
キーを入力する際は画面に表示されません。

```powershell
$geminiSecret = Read-Host -Prompt 'Gemini の API キー' -AsSecureString
$env:GEMINI_API_KEY = [Net.NetworkCredential]::new('', $geminiSecret).Password
$env:GEMINI_FREE_TIER_CONFIRMED = 'yes'
node .\server.mjs
```

ブラウザで http://127.0.0.1:4181 を開きます。停止するときは PowerShell で Ctrl+C を押してウィンドウを閉じます。
公開サーバーとしては使用せず、この PC 上で試してください。

- [Gemini API の課金と無料枠](https://ai.google.dev/gemini-api/docs/billing)
- [Gemini API の利用規約](https://ai.google.dev/gemini-api/terms)
